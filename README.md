# Tic Tac Toe - Mobile Web Game

A beautiful, responsive tic-tac-toe game designed specifically for mobile web development and perfect for testing in mobile IDE environments.

## Features

🎮 **Game Features:**
- Classic tic-tac-toe gameplay for two players
- Score tracking across multiple games
- Win detection with visual highlighting
- Draw game detection
- Smooth animations and transitions

📱 **Mobile-Optimized:**
- Responsive design that works on all screen sizes
- Touch-friendly interface with large tap targets
- Optimized for mobile devices and tablets
- Works great in mobile IDE apps
- No external dependencies - pure HTML, CSS, and JavaScript

🎨 **Visual Design:**
- Modern gradient background
- Glass-morphism design elements
- Smooth animations and micro-interactions
- Beautiful color scheme with accessibility in mind
- Professional typography

## How to Use

1. Open `index.html` in any web browser
2. Players take turns clicking/tapping cells
3. First player to get three in a row wins
4. Use "New Game" to start over
5. Use "Reset Score" to clear win counts

## Keyboard Controls

- **1-9**: Place marker in corresponding cell (number pad layout)
- **R**: Reset/new game
